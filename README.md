# Проект 2 - Поиск вакансий
Программа будет получать информацию о вакансиях с платформы hh.ru в России, сохранять ее в файл и позволять удобно
работать с ней: добавлять, фильтровать, удалять.


## Разработка
В одноименных модулях расположены функции/методы/классы для реализации проекта


### Установка зависимостей
Для установки зависимостей, выполните команду:
```sh
poetry update
```
или
```sh
poetry install
```
